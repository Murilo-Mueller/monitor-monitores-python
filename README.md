# monitor-monitores-python

O código é um sistema que está programado em _python_, ele mostra **4** tipos de motores e suas características. Também mostra se o motor tem algum tipo de **alerta**. No final, mostra um resumo com a _temperatura média, a corrente média, a potência total e o motor com a maior temperatura_.
***
Tabela com os valores dos motores:
Motores | Temperatura | Corrente | Vibração | RPM
:---  | :---: | :---: | :---: |  ---:
MTR-01 (Estamparia) | 68.4 C | 14.2 A | 2.1 mm/s | 1750
MTR-02 (Usinagem) | 84.7 C | 19.3 A | 5.2 mm/s | 1690
MTR-03 (Bobinagem) | 76.2 C | 17.8 A | 4.7 mm/s | 1520
MTR-04 (Pintura) | 61.0 C | 11.5 A | 1.8 mm/s | 1780
***
Sempre temos que interpretar os dados para não cometer erros, como diz Platão:
>Uma boa decisão é baseada no conhecimento e não em números **- Platão**
